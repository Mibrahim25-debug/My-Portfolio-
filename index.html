PropTech · Autonomous agent

Veridian — Autonomous Real Estate Intelligence

Outcome — hours of manual property research replaced by an agent that queries, calculates and reports on demand, so analysts review conclusions instead of assembling spreadsheets.

Aerospace · Air-gapped systems

NASTP Air-Gapped Examination Network

Outcome — a high-security aerospace facility runs digital examinations with zero internet dependency and zero external exposure, meeting protocols that ruled out every cloud option.

An enterprise-grade, fully offline client–server architecture. It bypasses the cloud entirely by establishing an asynchronous HTTP polling network across a local subnet, coordinating exam delivery and collection between machines that never touch the internet. A Pandas ETL engine ingests messy CSV question banks and normalises them into a clean SQLite store behind a PySide6 desktop interface.
